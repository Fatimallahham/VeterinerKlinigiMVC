# VeterinerKlinigiMVC
Bu proje, Web Programlama dersi kapsamında ASP.NET Core MVC ve .NET 10 kullanılarak geliştirilen bir veteriner kliniği yönetim sistemidir.

Projenin amacı; veteriner kliniğindeki randevu işlemlerini, evcil hayvan bilgilerini, veteriner hekimleri ve hasta kayıtlarını dijital ortamda yönetmektir.

Kullanılan Teknolojiler

ASP.NET Core MVC

C#

.NET 10

Entity Framework Core

ASP.NET Core Identity

HTML, CSS, Bootstrap

Git ve GitHub

Planlanan Özellikler

Kullanıcı kayıt ve giriş işlemleri

Admin, Veteriner ve Üye rolleri

Evcil hayvan kayıt ve takip işlemleri

Randevu oluşturma ve yönetme

Aşı ve muayene kayıtlarının takibi

Yetkilendirme ve kullanıcı yönetimi

Proje Durumu

Proje geliştirme aşamasındadır. İlk olarak temel MVC yapısı ve kullanıcı kimlik doğrulama altyapısı oluşturulmuştur.
